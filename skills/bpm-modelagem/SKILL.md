# Skill: bpm-modelagem
Esta skill fornece as regras técnicas de modelagem BPMN 2.0 (eventos, pools, lanes, gateways, subprocessos) para agentes encarregados de modelar ou validar o desenho técnico de fluxos de processos de negócio.

## Contexto de Uso
Utilize as referências anexadas para consultar comportamentos esperados do BPMN e elementos sintáticos sempre que gerar diagramas XML ou justificar decisões de modelagem técnica.

## Referências Inclusas
- **gnofi-curso-completo.md**: Curso Completo de BPMN (Gnofi Tecnologia), contendo definições de elementos essenciais de modelagem, ciclo de vida da atividade, uso correto de Gateways e decomposição.
